# 🔐 Gestor de Contraseñas PRO

Aplicación de escritorio para gestionar contraseñas de forma segura, con cifrado real, generación automática y recordatorios inteligentes.

## 🚀 Características principales
- **Cifrado real** con Fernet (cryptography)
- **Generación de contraseñas** seguras y personalizables
- **Exportación a Excel** con formato profesional
- **Recordatorios automáticos** de contraseñas vencidas
- **Estadísticas** de seguridad (débil/media/fuerte)
- **Búsqueda y filtrado** rápido
- **Instalador automático** (Windows)

## 📦 Requisitos
- Python 3.8 o superior
- Librerías: `cryptography`, `openpyxl`

## 🛠️ Instalación
1. Clona o descarga el repositorio.
2. Ejecuta `instalar.bat` (Windows) para instalar dependencias y crear acceso directo.
3. O manualmente:
   ```bash
   pip install cryptography openpyxl
   python gestor_contrasenas.py
